# Required cases of the non-device checkpoint and ignored-test lanes, one per line:
# lane<TAB>binary_id<TAB>test_name (binary_id and test_name are the identity nextest and JUnit report).
# Hand-maintained, sorted by lane, binary id, test name (LC_ALL=C), and never generated from a run. A lane is a
# `just` recipe that runs its rows by exact name (an `#[ignore]`d row too: scripts/check-lane-coverage.py
# `--lane-filter <lane>` prints the filterset), and the `checkpoint*` lanes set POOT_REQUIRE_MODELS=1, so a
# model missing from the models directory fails the row instead of skipping it. The llamacpp_longrope_tests rows
# also need the F16 GGUFs of Phi-4-mini and Phi-3.5-mini in the models directory: scripts/make-f16-ggufs.sh.
# scripts/check-lane-coverage.py (`just test-lane-coverage`) fails when an inventory row of class `checkpoint`
# is in no lane, when an `#[ignore]`d test is in no lane's list (here or in scripts/required-device-cases/), and
# when a row here names no test.
#
#   checkpoint           `just test-checkpoint`: CPU rows over the small checkpoints in ~/models; the dev box.
#   checkpoint-large     `just test-checkpoint-large`: rows that read a 20B+ checkpoint (header or tensors):
#                        NEVER on the dev box; a pod or host with the checkpoints and the memory for them.
#   npu-toolchain        `just test-npu-toolchain`: the rows that need the pinned Peano llc and the IRON driver.
#   real-dims-long       `just test-real-dims-long`: real-dimension rows too slow for `just test-real-dims`.
#   regen-kernel-assets  `just regen-kernel-assets`: the generator that rewrites the committed kernel assets.
#
# The device lanes' rows (wgpu, ROCm, PTX, Vulkan, and the large-checkpoint twins) are the `checkpoint-<backend>`
# and `checkpoint-large-<backend>` lists in scripts/required-device-cases/, which the required-case gate reads.
