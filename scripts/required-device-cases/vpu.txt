# Required cases for `just test-device-vpu`, one per line:
# binary_id<TAB>test_name, the identity the lane's JUnit report carries as classname and name.
# Hand-maintained: never generated from the justfile's selection. The gate
# (scripts/check-required-cases.py vpu) fails the lane unless every case here ran and passed - a skip is
# never a pass. Sorted in canonical (LC_ALL=C) order.
#
# Every poot-npu `vpu` row, on the Intel NPU through the real compile -> Engine -> vendor graph compiler ->
# Level Zero route: the op bank against the shared oracle (elementwise incl. sub, max, ge, div, neg, sqrt and
# scalar literals, transcendental, reduction sum and max, contraction, gather incl. by an iota, update-slice at a
# literal and a runtime index, movement, rank four, F32 at the boundary, carried state), one compiled graph and one replay per step,
# the planner's typed refusals for the NPU target, unload releasing every buffer, capture and replay. The blob
# cache: a second device loading the cached blob without the compiler, a damaged or foreign entry recompiled,
# a blob the driver rejects recompiled. The device's own contract: the compiled graph against the region's
# ABI (name, count, direction, extents, precision), the rank bound, the vendor compiler's log, dispatch
# refusals, and the failed replay's poison. The Qwen2.5-0.5B-dimension block (POOT-1175): its
# attention core and MLP in F16 against the oracle (its refusal table is a model-free row in poot-models).
# Hardware-free unit rows ride along (the layer rejection, the
# padded dimensions, the cache key, the cache write, the precision refusal).
